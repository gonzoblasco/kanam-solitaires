# ♠ Kanam's Solitaires ♥

A collection of solitaire card games for the web. No frameworks, no dependencies — just vanilla HTML, CSS, and JavaScript.

## Games

- **Klondike** — the classic. Draw, build, and clear all four foundations.
- More coming soon: Spider, FreeCell, Pyramid...

## Play

👉 [kanam-solitaires.gonzoblasco.dev](https://gonzoblasco.github.io/kanam-solitaires/)

## Development

```bash
npm install
npm run dev     # dev server
npm run build   # production build
npm run preview # preview production build
```

## Stack

- [Vite](https://vitejs.dev/) — build tool
- Vanilla JS — no framework
- CSS Custom Properties — theming
- GitHub Pages — deployment
